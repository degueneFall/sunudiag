À propos du paludisme

Le paludisme est transmis par la piqûre d’un moustique infecté. Fièvre, frissons et fatigue sont les premiers signes. Un diagnostic rapide améliore nettement les chances de guérison.

Le modèle SunuDiag s’appuie sur cinq indicateurs cliniques simples et un jeu de données local (DataSANTE-221) pour estimer une probabilité, sans jamais remplacer un test biologique.

Se protéger du paludisme

  • Dormir sous une moustiquaire imprégnée
  • Éliminer les eaux stagnantes autour du logement
  • Consulter dès les premiers symptômes
